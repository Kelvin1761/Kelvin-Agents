# Stage5 native resource binding — unfinished engineering

## Current slice: actual HKJC sectional reader

This is a native API seam through score_logic_data -> _attach_past_runs ->
past_runs.attach -> _sectional_ft. It is not a new frozen input/control protocol,
a full materializer, OS sandbox, PIT availability proof or permission to run a
historical pilot. No supervised harness or parent/worker power guard is changed.
The contract-extension proposal remains unapproved.

An omitted sectional_source preserves the existing production load/cache policy.
An explicit SectionalSource binds an absolute local path and exact raw SHA256.
Hash=None declares that exact path absent, checked before any enrichment. The
explicit route reads bounded regular nonsymlink bytes through a stable descriptor,
checks path/descriptor identity and raw hash, rejects malformed/nonfinite/duplicate
JSON, and passes the resulting table through the actual full native scorer.
It does not read, replace or clear the default _TABLE cache, resolve HOT defaults,
or fall back on a failed binding. Absence is separate from default selection.

Native FT arithmetic, prior/enrichment hooks, field adjustments, rounding and final
ranking remain in the full path. Already embedded sectional_ft data is not silently
cleared when an absent table yields no new value: input canonicalization is a
separate unfinished audited-boundary problem, not permission for a scoring change.

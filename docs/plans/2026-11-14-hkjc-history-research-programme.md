# HKJC 歷史語料研究計劃（2026-11-14）

- **狀態**：草稿，等 Kelvin 確認次序
- **前置**：`2026-11-13-hkjc-historic-engine-replay.md`（歷史引擎回放）—— **忠實度閘未過，以下全部唔開始**
- **觸發**：Kelvin 2026-11-14 列咗八項：泥地、國際賽日（外隊馬／外國騎師）、refit、forward 測試、重試 REJECT、新訊號、初出馬、直路賽

## 0. 點解要先有計劃
八項工作會喺**同一份**回放語料做幾十次比較。每試一次，holdout 就「用」咗少少：試夠多次，總有一個靠運氣過關。
所以先定：語料點切、每項試幾多個候選、holdout 幾時先准睇。

## 1. 語料切法（寫死，之後唔准改）
| 段 | 季 | 用途 |
|---|---|---|
| burn-in | 2019/20 | 只做騎練評分、標準時間、往績嘅歷史，唔評分 |
| **dev** | 2020/21 – 2023/24（4 季，約 3,300 場） | 揀候選、調參數、逐季 walk-forward |
| **holdout** | 2024/25 – 2025/26（2 季，約 1,650 場） | 每個家族只准睇一次，用嚟確認 |
| **terminal** | 2026/27（live 449 場 + 之後 forward） | 最後確認；同 live 引擎語料比較 |

- 判準沿用 `docs/model-evaluation-contract.md`；**Gold、Good 都唔可以負**（Kelvin）。
- **holdout 登記簿**：`docs/experiments/holdout-ledger-hkjc-replay.md`，記低每次睇 holdout 嘅候選同結果。
  每項工作預先寫低最多幾多個候選會去 holdout（預設 ≤ 3），同一項入面用 Holm。
- 每個候選都要過「隨機洗牌 null」：同幅度、冇資訊嘅改動跑 200 次，候選要高過 null 先算數（EXP-09 教訓）。

## 2b. 現有訊號審計（第 2b 步）
逐個現有 leaf 同微調項（段速五級門檻、能量、L400 趨勢、引擎類型、人馬歷史 ±4、騎練組合／同程、換騎、
form_line 上限同加分、SIP-C、race_shape ±10 收窄、consistency override、distance_fit、健康扣分……）：
1. **消融**：設做中性，量 Gold／Good／capture@5／頭二選有中，對隨機洗牌 null。
2. **方向**：條件化 cohort 超額（同層比較），睇加減分方向啱唔啱（AU 試過騎師連續性三項全反）。
3. **已知 bug**：form_line「強」字子串怪癖（「中弱」「無資料」都攞 78 分）—— 當正確性修正處理，量後果。
判法：剷走唔輸（Gold、Good ≥ 0）而且唔好過 null 嘅 → 噪音候選，可以剷（簡單 > 複雜）；方向錯嘅 → 修正候選。
dev 揀，holdout 一次確認一整批（唔逐個睇）。

## 2c. 負磅喺新段速點反映（第 4 步一齊做）
現行：L400 已經按負磅差換算到今仗（每磅 0.007／0.016／0.021 秒按路程，EXP-20261112-04）；評分與經驗維度讀評分差距；
SIP-C 要負磅 ≤ 全場中位數。**新段速（前段、全程對標準）未換算負磅。**
1. **先量**：74,000 匹次、同一匹馬唔同仗比較，逐段（第一段、中段、倒數第二段、L400）、按路程量每磅慢幾多秒。
   預期（EXP-07）前段幾乎冇影響；要用數據確認，唔假設。
2. **再試**：段速 arm 分「冇換算」同「按量出嚟嘅逐段係數換算到今仗負磅」兩個版本，預先登記，兩個都報。
3. **雙重計算**：讓磅賽負磅 ≈ 評分；往績換算到今仗負磅會罰今仗重磅馬，評分差距就獎勵評分高嘅馬，方向相反。
   要量兩樣嘅相關同「一齊放」嘅效果，唔可以分開判。

## 2a. 評分、配備、馬房出擊（第 9b 步）
全部用賽日之前嘅資料（as-of）；**賠率／市場唔入模型**，只可以做「市場鏡頭」分析（睇市場有冇已經反映）。
| 假設 | 定義（跑之前會寫死喺腳本） | 舊記錄 |
|---|---|---|
| H1 評分跌到有競爭力 | 今仗評分 vs 近 N 仗評分高位／同班入位馬平均評分；跌幅分段 | well-in 兩次 REJECT（EXP-20261111-08、EXP-20261112-22）—— 唔同問法，但要先證明唔係同一訊號 |
| H2 評分接近或低過上次贏馬時水平 | 今仗評分 − 上次贏馬嗰仗評分（冇贏過 = 缺失）；≤ 0、≤ +3 等分段 | 未測過 |
| H3 配備改變 | 初戴眼罩（B）、除眼罩、改用其他（TT、CP、XB…）；連「呢匹馬過往戴／除配備之後嘅表現」 | HKJC 未測；AU 配備變更同 form 重複 |
| H4 馬房出擊模式 | 練馬師層面：換上頂級騎師、降班、換配備、評分到贏馬水平、短休後出等**組合**；每個練馬師嘅歷史「出擊命中率」as-of | EXP-20261027-12：P1 換上頂級騎師有訊號（+5.5pp，Holm 0.025，市場已反映、模型漏咗），P4／P10 出擊組合冇訊號；當時只得 2024 起，而家有 7 季 |
- 每個假設：dev 篩 → 模型之上係數（Holm）→ 引擎 A/B（加做 overlay 組件）→ holdout 一次。
- H4 組合多，最易 data-mine：預先寫死 ≤ 6 個組合，唔准睇完結果先加。

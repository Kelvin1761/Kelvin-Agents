## 點解唔可以當 edge 用住

1. 方向唔係預先登記嘅；holdout 已經睇過，再喺同一批數據定規則 = 用 holdout 揀。
2. dev 嘅效應細好多，CI 跨零。
3. 量嘅係**收市價**；我哋 21:00 落注時嘅價（早 10–20 個鐘）可能已經唔同。
4. log-loss 改善只係每場 ~0.001，細過 Sportsbet 抽水好多。

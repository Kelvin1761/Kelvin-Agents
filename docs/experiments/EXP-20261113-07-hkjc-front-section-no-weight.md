# EXP-20261113-07 — HKJC 前段組件唔換算負磅

- 日期：2026-11-13
- 平台：HKJC
- 決定：**REJECT（四個）**—— 同有負磅版本幾乎一樣

## 假設

Kelvin：「前段組件唔加負磅呢？前段負磅基本唔影響」。EXP-04／06 嘅前段值有按段長換算負磅，可能引入噪音。

## 方法

`patches/hkjc_front_section_noweight.py`（喺 repo root 行，參數 = labels_final 所在 scratch 目錄）。
同 EXP-06 一樣嘅離線框架，只改一樣：前段偏差唔加負磅換算；標準化 mean／SD 喺 dev 半重估。
V0 雙向、V1 單邊；b ∈ {0.25, 0.5}；dev < 09-06（263 場）、holdout（186 場）；null = 場內調換 z 100 次；有負磅版同框架做對照。

## 結果

- **有／冇負磅兩個值相關 r = 0.990**；差異 SD 0.026 vs 值 SD 0.188 秒／400 米 → 負磅換算只郁大約 14% SD，Kelvin 講得啱，前段負磅影響好細。
- 因此結果同有負磅版差唔多：

| 版本 | dev Gold／Good | holdout Gold／Good | holdout Gold null 百分位 | holdout capture@5 null 百分位 |
|---|---|---|---|---|
| 冇負磅 V0 b=0.25 | −0.38／−1.52 | −2.69／−1.61 | 0% | 68% |
| 冇負磅 V0 b=0.5 | −0.38／−0.76 | −2.15／−2.69 | 21% | 94% |
| 冇負磅 V1 b=0.25 | −0.76／−0.76 | −2.15／+0.00 | 1% | 71% |
| 冇負磅 V1 b=0.5 | −1.14／−0.38 | −2.69／−0.54 | 5% | 57% |
| 對照 有負磅 V0 b=0.5 | −0.76／−1.14 | −2.15／−2.15 | 23% | 88% |

## 「模型睇 L400 唔睇前段唔合理」—— 模型真係冇睇前段

前段 z 同各維度 Spearman：race_shape +0.002、draw +0.000、sectional −0.050、stability +0.235、form +0.239。
即係前段資訊模型冇（同檔位／走位維度完全正交），只有少少經近績間接反映。
但三種放法（雙向、單邊、單邊＋步速）× 有／冇負磅都令 Gold 跌，holdout Gold 經常差過隨機調換。
最好嘅只係 capture@5（冇負磅 V0 b=0.5 holdout 94 百分位）—— 接近但未到 95，而且 dev 只 90。

## 結論

負磅唔係問題所在。前段訊號真、模型冇，但呢 449 場上面放入排名唔改善 Gold／Good。
前段已經試咗 14 個變體，唔再喺同一批場次試；要再判就用新場次 forward shadow。

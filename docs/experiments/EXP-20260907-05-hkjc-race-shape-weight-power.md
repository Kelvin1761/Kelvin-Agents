## 一：功效計算

由已記錄嘅實測效應量反推。輸入全部係舊記錄裡面嘅數字，唔係假設：EXP-20260902-03 嘅 84 場 holdout 配對 bootstrap CI，同 EXP-20260902-08 嘅前置 power audit。

由 CI 半寬回推 `σ`（`se = 半寬 / 1.96`、`σ = se · √84`），再求 `N = (1.96 · σ / |Δ|)²`。

⚠️ **呢個回推係近似**：原始 CI 係配對 bootstrap 百分位區間，唔對稱（例：`good` 係 [−7.14, +8.33]，中心 +1.16 兩邊差 8.30 / 7.17），而我用嘅係平均半寬當常態 se。所以下面嘅 N 係量級估計，唔係精確樣本量。方向同量級可信，個位數唔可信。

### 呢個計算翻轉咗一個假設

直覺講法係「等夠場數，低權重就會平反」。**計完之後呢個講法企唔住**：

唯一一個功效已經夠（85 vs 84，剛剛好喺邊界）嘅指標係 `champion`，而佢係 **−5.93pp [−11.90, 0.00]** —— 方向係**反對** refit。其餘七個都係「量唔到」。

即係現時嘅證據狀態係：**一個近乎有功效嘅指標反對，七個冇功效**。唔係「七個支持但功效不足」。所以繼續累積語料**唔保證**會平反 0.17–0.23，同樣可能係確認 27.37%（或者確認 `champion` 真係會蝕）。

`good` 要 3,735 場（≈4.7 季）呢一行亦要留意：佢唔係「要等」，係**用 `good` 判呢個改動結構上唔可行**。判決規則要事先講清楚用邊個 primary，唔可以事後揀。

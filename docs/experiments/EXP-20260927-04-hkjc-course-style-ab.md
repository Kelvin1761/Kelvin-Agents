# EXP-20260927-04 — HKJC 場地適性、欄位線同預測跑法 A/B

## 問題

1. 跑馬地 A/B/C/C+3 欄位線是否應改變固定內／中／外檔先驗？
2. 沙田同跑馬地是否需要兩套完整公式？
3. 模型有冇真正使用田草／谷草／泥地性能？
4. 最近兩次跑馬地逐馬跑法預測只有約 44–46% 命中，應否移除？

## 方法

- 247 場非 legacy HKJC Logic，全引擎重新評分。
- 騎練先驗逐個賽日以 `Date < meeting_date` 重建。
- rail prior 同樣只用嚴格早於賽日嘅結果。
- 每個候選獨立消融，逐場配對 bootstrap 2,000 次，seed 7。
- harness：`docs/experiments/patches/hkjc_course_style_ab.py`。

## 結果

### A. 只移除「今仗預測跑法」及信心修正 — KEEP（正確性／表達修正）

保留已完成賽事嘅真實走位窗口、PI、內外疊同檔位匹配；移除逐馬「前置／守中／後上」
預測、自動步速圖、報告中「預計…」字眼，以及跑馬地由預測信心帶來嘅 ±0.8 修正。

| metric | Δ | 95% CI |
|---|---:|---:|
| Gold | +0.00pp | [+0.00, +0.00] |
| Good | +0.40pp | [−0.81, +1.62] |
| Gold strict | +0.00pp | [+0.00, +0.00] |
| Min | +0.00pp | [+0.00, +0.00] |
| Champion | +0.00pp | [−1.21, +1.21] |
| NDCG@5 | +0.15pp | [−0.12, +0.46] |

沙田所有場數 KPI 完全相同；跑馬地 Good 27.84%→28.87%、NDCG 57.43%→57.80%。
呢個**唔係已證實表現改善**；保留原因係低命中預測不應包裝成事實，而且主要指標零顯著退步。

### B. 將所有歷史走位匹配一併移除 — REJECT

Gold −2.83pp，95% CI [−4.86, −0.81]；Gold strict −2.02pp
[−4.05, −0.40]。問題係「今仗預測跑法」，唔係已觀察歷史走位本身；後者必須保留。

### C. 同場同程 EB 直接加到 race-shape — REJECT

Good −3.24pp [−6.48, −0.40]。雖然跑馬地 Gold 點估計較高，沙田相反，係典型 cohort
符號分裂，唔可以用 pooled 次要改善合理化。

資料審計另外發現：`沙田AWT` 同歷史「沙田全天候／沙田泥地」用 exact string 比較，令
AWT 同場同程 **456 匹全部零命中**。已正規化場地＋surface key；呢個只修未來 Facts
統計，未將場地適性加落排名。

### D. rail×distance×field draw prior

| arm | Gold Δ | Good Δ | Min Δ | Champion Δ | NDCG@5 Δ | 決定 |

| 重新排 inner/middle/outer | +0.00 | −0.40 | −0.81 | +0.81 | +0.07 | REJECT |

連續版方向較合理，但所有主要／排序 CI 仍跨零；跑馬地 Good 27.84%→23.71%，即使
Gold 14.43%→15.46% 都過唔到 guardrail。保留 shadow，唔改 live draw formula。

## 沙田／跑馬地是否拆公式

**唔拆完整 7D。** 證據只支持保留現有 venue-specific race-shape component：沙田同
跑馬地 baseline 表現唔同，但候選效果亦互相反向，未有一套新公式可以兩邊 primary
都不回歸。正確方向係共用 7D 骨架，對 rail／course／surface 做細粒度、可獨立驗證嘅
場地 component，而唔係複製兩套難以維護嘅總公式。

## 最終決定

- **KEEP**：刪除預測跑法／自動步速圖嘅評分直接影響同對外展示；保留歷史實際走位。
- **KEEP（資料正確性）**：AWT 場地名稱正規化。
- **REJECT**：同場同程直接加分、rail 離散重排、全走位模組移除。
- **SHADOW ONLY**：rail 連續幅度候選，等更多賽事先再判。
- **NO SPLIT**：沙田／跑馬地暫不拆完整公式。

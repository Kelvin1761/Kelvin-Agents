## 點解同 EXP-72 R 唔同

R 用**絕對**同場上名率：上名率低嘅馬通常本身就弱，近績同穩定性已經講咗，所以重複計、Gold 跌。
今次用**相對生涯**：「呢匹馬喺呢個場地／今日地況，係咪跑得好過佢平時」。佢自己生涯上名率做先驗，所以平時弱嘅馬唔會因為弱而被扣。
另外**好地往績由來冇讀到**：抽取 `going_stats_line` 用 `好地: (...)` capture，標籤被食咗，`_parse_going_stats` 只認 `軟地:`／`重地:`，
所以好地日（約一半賽事）地況部份永遠 0。

## 候選公式（全部預先定死）

    生涯率 c = (生涯上名 + K·P0) / (生涯出賽 + K)
    專長 rel(紀錄) = (紀錄上名 + K·c) / (紀錄出賽 + K) − c        冇出賽 → 0
    track_score = clip(60 + S × (rel(同場) + rel(今日地況 bucket)), 0, 100)

- K = 4（同濕地 overlay 一樣）；P0 = **0.3715**（08–09 月 20,481 匹賽前生涯紀錄匯總上名率；賽前資訊，唔睇賽果）；
- S = **50**：令場內 SD 同而家 track_score 一樣（4.68 ÷ 0.0929 = 50.4），咁維度係數 0.1411 唔使 refit；
- 今日地況 bucket：好地／軟地／重地（`going_bucket`），好地讀 `going_stats_line` 第一段（冇標籤嗰段）；
- 生涯紀錄：`career_record_line`（`21 : 8-3-0`）；冇 → c = P0。
- 取代而家同場段（上名 +5／贏 +2.4／0 上名 −8.81／−0.81）同地況段（上名 +0.8×、濕地曾贏 +3.77、0 上名四級扣分）。

## 判決

v3 `fixed_rule` 全紀錄（08-05 起），ranking metric `top3_capture_at5`、`ndcg_at5`、`top5_pairwise_auc`；賽日 bootstrap 2000 次、seed 7；
三個 arm Holm 校正。**採用**：verdict 係 PRIMARY_WIN 或 RANKING_WIN，而且冇預先聲明分層 CI 全負。
分層：今場地況（好地／Soft 5–6／Soft 7+／Heavy）、馬匹數、首選 SP、路程。
多個 arm 合資格 → 揀最簡單：SPW > SP > SPG。冇 arm 合資格 → REJECT，記錄點失敗；live 唔郁。
**唔准**睇完結果先改 K、P0、S 或者 arm 定義；要改就開新實驗。

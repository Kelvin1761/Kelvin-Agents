# EXP-20261111-14 HKJC「負磅著數」：實際負磅 vs 評分應負嘅磅數差（screening）

- **日期**：2026-11-11（假設同判決規則喺睇結果之前寫）
- **平台**：HKJC
- **觸發**：Kelvin：「評分做 base，負磅做調整」；「如果淨係睇官方評分，會唔會過度 favor 高分嘅馬，低分啲但係輕磅有著數嘅馬就會睇唔到？」
- **前置**：EXP-20261111-13（評分與經驗改名）、EXP-20261111-10（官方評分分上線）、EXP-20261111-08（well-in：用模型能力搵評分低估嘅馬，冇訊號）
- **改到嘅檔案**：**冇。純量度**

## 概念
讓磅賽入面負磅 ≈ 評分（每 1 分 1 磅），所以「評分低 → 負磅輕」**本身唔係著數**，係讓磅官設計出嚟嘅補償。
真正嘅著數係**實際背嘅磅少過評分應該背嘅磅**：
- 評分應負 = 場內最高宣佈負磅 − 評分差距（距全場最高評分幾多分）
- 編排差 = 評分應負 − 宣佈負磅（底磅壓縮 → 負數＝蝕；頂磅封頂／非讓磅賽 → 可正可負）
- **負磅著數（磅）= 評分應負 − 實際負磅 = 編排差 + 見習減磅**

## 假設
模型分（完整 live 模型）固定之後，負磅著數越大，上名機會越高。

## 方法（預先定）
- 語料：`hkjc_eval_harness run --dump-matrix`（PIT，baseline = EXP-20261111-10 上線後 main），排位表讀評分、宣佈負磅、見習減磅
- 讓磅賽（第一至第五班），剔初出馬同冇評分嘅馬
- 主測試：場內上名 logistic `place ~ z(模型原始分) + 負磅著數(磅)`，著數係數 95% CI（場次 bootstrap 1,000）
- 分層：著數 = 0／1–4 磅／≥5 磅（主要係見習減磅）對比上名超額（相對模型預期）
- 先印分佈：幾多匹馬著數 ≠ 0、來源（減磅 vs 編排差）

## 判決規則（只開一次）
- **PASS（開引擎 A/B）**：著數係數 > 0 而且 CI 下界 > 0
- 係數 CI 上界 < 0 → REJECT（著數反而唔利，例如見習騎師本身差）
- 其他 → REJECT（冇訊號）
- 唔換定義、唔剔見習騎師去救

## 結果（2026-11-11，只開一次）
- 語料：PIT 回放（baseline f35c94d7 之後 main，已含評分差距）讓磅賽 **343 場 / 4,185 匹**（2026-05-03 → 2026-11-08）
- 著數 ≠ 0：**23.0%**；幾乎全部嚟自見習減磅（22.2%：2 磅 512、3 磅 91、7 磅 224、10 磅 100）；編排差 ≠ 0 只 **1.2%**（全部係負，即底磅壓縮）

| 測試（模型分固定） | 係數（每磅 log-odds） | 95% CI |
|---|---|---|
| **負磅著數（主測試）** | **−0.0129** | **[−0.0482, +0.0221]** |
| 拆開：見習減磅 | −0.0109 | [−0.0467, +0.0245] |
| 拆開：編排差 | −0.0856 | [−0.2480, +0.1690] |

| 著數 | n | 上名 | 模型預期 | 差 |
|---|---:|---:|---:|---:|
| ≤ −1 磅（蝕） | 46 | 21.7% | 17.0% | +4.78pp |
| 0 | 3,222 | 25.2% | 24.8% | +0.35pp |
| 1–4 磅 | 596 | 18.8% | 20.6% | −1.84pp |
| ≥ 5 磅 | 321 | 23.4% | 24.2% | −0.79pp |

**判決：REJECT（冇訊號）。** 模型分固定之後，輕咗嘅磅冇令匹馬跑得好啲；點估計仲係微負。
可能解釋（**未量度**）：見習減磅本身係為咗補償見習騎師經驗少而設，兩樣抵銷；而且騎師分已經睇緊騎師本人。
編排差（底磅壓縮）得 1.2% 匹馬，樣本太細判唔到。

## 結論
回答 Kelvin：「淨係睇官方評分會唔會睇唔到輕磅有著數嘅馬？」—— 呢個樣本（343 場）**冇量到**呢類馬喺模型之上有額外表現：
評分低→負磅輕係讓磅官嘅補償（而且補償唔夠，高評分照跑得好啲）；實際負磅少過評分應負嘅（主要係見習減磅），
喺模型之上冇額外上名。連同 EXP-20261111-08（well-in），「負磅著數」兩種講法都冇剩餘訊號。**唔開引擎 A/B。**

**決定**：REJECT

## 2. 跑法多變嘅馬
現行（`draw_style.habitual_position`）：之前最多 6 仗早段位置**平均**，再分前置／中置／後上。多變嘅馬平均落中間 → 多數派做中置。
- 有分類嘅 57,053 匹次：86.3% 近 6 仗有多過一類；40.4% 係「有前置又有後上」嘅多變馬（派到 中置 73%、後上 21%、前置 5%）。
- **上線之後嘅殘差**（入頭三 − 校準機率，按檔位段 內／中／外，±1.96 SE）：
  | 群 | 2021–23 | 2024+ |
  |---|---|---|
  | 多變 | +3.7±1.5／+0.2±1.2／−0.7±1.4 | +0.2±1.7／+1.4±1.4／−0.4±1.6 |
  | 穩定（全同一類） | −0.1／+0.9／−0.4 | −0.0／−0.3／−2.0±2.4 |
  | 其他混合 | +0.7／+0.4／−1.0 | −0.8／+0.0／−2.7±1.4 |
  多變馬內檔 +3.7 只喺 2021–23（部分係格表嘅訓練期），2024+ 冇咗 → 冇一致殘差。
- 預先登記候選 **SDmix**：多變／混合馬嘅跑法格值改用「近 6 仗跑法分佈加權」（例如 3 前 3 後 → 前置格、後上格各一半），其他不變；同一套逐季 walk-forward（`patches/hkjc_draw_style/build_mix.py <base> <prefix> mix|mean`），對 SD（mean）比：
  dev Δlog-loss +0.00002 [−0.00013,+0.00017]、場內 AUC −0.0012 [−0.0019,−0.0004]、Gold −0.12 → **REJECT**。
→ 平均法對多變馬已經夠：多變馬嘅檔位效應本身就似中置（介乎前置同後上之間），加權分佈反而加噪音。現行處理唔改。

## 結論

**Q1 = 得，而且損耗量得出**：現行把組合攤成 0.55/0.45 再重組，淨傳導率只有 0.505 ——
一半訊號係俾表示法本身食走，唔係俾數據食走。連續值 vs 現行離散門檻喺 681 場
out-of-sample 顯著贏 +0.0022。**兩個改動應該拆開測**（獨立 leaf ／ 連續化），
唔可以一次過改完就話贏（`feature-ablation`）。

**Q2 = 練馬師得，騎師唔得**。騎師場地偏好喺兩季資料入面同噪音分唔開：
真訊號只佔 1% 方差、拆半重測 r=+0.072、跨季 r=**−0.160**（負數＝上季偏好對今季係
反指標，典型均值回歸）。而且單獨 AUC 0.4628 < 0.5。
練馬師相反：73% 方差係真訊號、拆半 r=+0.639、跨季 r=+0.504、覆蓋 97.3%，
而且**贏過現行已入分嘅「練馬師同程」**——反過嚟同程加落場地之上就唔顯著，
即係場地部分包住咗同程。

**Q3 = 唔得，係樣本問題唔係概念問題**。組合本身只有 650 對、48.7% 出賽行夠 40 仗；
再拆兩個場地之後 ≥50/50 仗得 17 對、覆蓋 16.4%。Δ AUC 準確咁等於零。

**未做嘅嘢（呢份唔係 KEEP 判決）**：以上全部係 screening harness 嘅 place-probability
AUC，唔係引擎真 baseline。baseline 用嘅係 EB 上名率超額，唔係引擎真嘅
`jockey_score`／`trainer_score`（勝率制、負向縮放、tier fallback）。
要落 production 一定要行 `docs/model-evaluation-contract.md` 同 Stage 4 v2 把尺
（Gold/Good primary），因為 memory `stage4-v2-is-the-ruler` 講過同一個改動用
AUC-only 同 Stage 4 v2 會出相反判決。ΔAUC +0.0026~0.0029 呢個幅度亦要先過
`au-gate-cannot-judge-11-of-14-leaves` 嗰條功效檢查。

# 第三部分：擺邊度先啱（2026-09-06）—— 兩樣上線

Kelvin 追問兩條：(1) 組合可唔可以**保持同一個權重**，淨係喺報告做獨立一節；
(2) 訊號既然係真嘅，就要搵個位放入分析。呢部分逐個位測。

## Q1 重新理解：「同一個權重的獨立一節」＝ 恆等變換

```
維度 = 0.55·騎師 + 0.45·練馬師
     = 0.55·(騎師 − 0.55a) + 0.45·(練馬師 − 0.45a) + (0.55²+0.45²)·a
```
右邊就係「騎師分（扣返組合）、練馬師分（扣返組合）、騎練組合淨 0.505a」三項。
**左右完全相等**，所以呢個要求根本唔使改任何分 —— 係一個純報告拆解。

實測核實：193 場 / **2,438 匹馬逐匹對 `ability_score`，0 匹有差異（bit-identical）**，
`檢查.sh` 兩個 golden 都綠。

唔係**次序** —— 郁唔郁得到排名同佢準唔準係兩件事。

### ⚠️ 一個要記住嘅量度陷阱（自我更正）

第一次跑呢個回歸得出「每 1 SD +0.2pp，CI 不跨零」，同五分位表 +20.5pp 完全矛盾。
原因：`t_dv` 幅度只有 ±0.08，而 `LogisticRegression` 預設 `C=1.0` 嘅 L2 罰則
**將係數壓到接近零**，個「CI 不跨零」係正則化假象。標準化 + `C=1e6` 之後
先係上面嗰組數。**細幅度特徵一定要標準化先入 sklearn。**

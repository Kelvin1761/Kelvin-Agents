## 方法

`patches/hkjc_results_db_signal_screen.py`。賽果庫 5,206 場（2019-09 起），基礎模型 B = EXP-11 基礎特徵＋輸頭馬等級＋表現數字。

## 解讀

- 係數過 Holm 嘅三個（F1、F1b、F5）都**冇一個令 Gold／Good CI 全正**；全部幅度 < 0.4pp，喺引擎 389 場（MDE 約 2pp）測唔到。
- F1 步速×跑法方向符合預期（前置馬多 → 前置馬蝕），但幅度細。
- F1b「前置跑法」有正係數：基礎模型 B 冇跑法；引擎已經有 race_shape（檔位／跑法），所以喺引擎上要再量正交性先可以諗。
- 體重變化、降班、騎師手風、上仗受阻：冇訊號。
- 未入引擎：賽果庫嘅細訊號喺 389 場引擎語料冇 power，A/B 只會量到噪音（EXP-24 null：任何同幅度改動 ≈ ±1.7pp Gold）。

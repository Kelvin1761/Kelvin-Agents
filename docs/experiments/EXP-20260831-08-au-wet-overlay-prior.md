### 錯個 prior 唔係無害嘅水平偏移

收縮式將**冇濕地往績**嘅馬留喺 prior（overlay = 0 = 中性），將**有往績**嘅馬
拉向佢自己嘅真實率。prior 高咗 0.124，所以一匹**正正跑到群體平均**嘅馬
會被罰，而且濕地經驗越多罰得越重：

| 濕地出賽 | 舊 overlay |
|---:|---:|
| 0 | 0.00 |
| 5 | −1.03 |
| 20 | −1.54 |
| 40 | −1.68 |

**「冇濕地往績」＝中性，「有平均濕地往績」＝被罰。** 2026-08-30 四個場次實測
overlay 中位數 −1.49，正正係呢個假象。

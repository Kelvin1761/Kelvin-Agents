## 3. 解讀
1. **純規則揀腿冇邊際優勢**：整體 −6.3%，CI 剛好包 0。莊家價比 L10 命中率更準，所以「L10 高」本身唔係 edge；最多係跟住市場。
2. **「邊類 stat 較可靠」只得部分支持**：PTS／REB 比 AST／3PM 蝕得少（−3% 對 −9～−11%），但四個 CI 全部包 0，**唔可以用呢個數據宣稱 PTS／REB 有優勢**。
3. **同 2 日實盤樣本唔一致嘅地方（要小心）**：實盤 3PM 8/9 中，呢度 3PM 係第二差（n=331）→ 2 日 3PM 結果更似運氣，**3PM 唔再建議入穩膽白名單**。實盤 AST 39%、呢度 AST 實際 64.9%：實盤過度自信嘅幅度（預測 88%／實際 60%）遠大過呢度 L10 對市場嘅差距（隱含 72%／實際 68%），即係**引擎嘅 98% 上限同調整項放大咗誤差，而唔只係 L10 本身**。
4. **價位段**：1.30–1.45 係唯一中性（+0.7%）；1.20–1.30 −10.2%（CI 全負）；≥1.45 全部負。所以早前「賠率 <1.45 較好」只啱一半，**真正差嘅係兩頭**：太短（抽水吃晒）同太長（同分歧大）。
5. **結構性提醒**：單腿已經 −6%；3 腿組合複利抽水，莊家 SGM 再加關聯性定價，**穩膽組合喺市場價之上冇系統性優勢，除非機率層真係贏到市場**。呢點同 tennis／AU 嘅經驗一致（見 memory `takeout beats the edge`）。

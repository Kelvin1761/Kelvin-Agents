# EXP-20261112-15 HKJC「真」步速修正概念測試（全場領放馬分段量步速）

- **日期**：2026-11-12 ｜ **平台**：HKJC
- **觸發**：Kelvin：「我想做真正嘅步速修正偏差，要搵返步速，可能睇完成時間？」
- **假設**：用賽果庫全場（領放馬）累積時間量嗰場步速，對馬會標準時間做真正步速修正（再扣當日場地快慢、換算負磅），
  預測力好過現行「輸頭馬秒數」
- **搜索過嘅舊記錄**：EXP-20261112-07／-09／-10／-11
- **改到嘅檔案／組件**：冇 live 改動；`hkjc_true_pace_concept.py`

## 定義（跑之前寫喺腳本 docstring）
- 步速 = 領放馬到最後一段之前嘅累積時間 − 標準分段（除最後一段）；場速 = 頭馬時間 − 標準時間（班次／路程／場地，賽果庫有班次）
- k（只用 2019/20，821 場）= **0.633**：早段每慢 1 秒全程慢 0.63 秒；corr(步速, 場速) = +0.70
- D0 對標準｜D1 = D0 − k × 步速（真步速修正）｜D2 = D1 − 當日同場地其他場次嘅剩餘快慢｜D2W = D2 換算今仗負磅｜M 輸頭馬秒數
- 近 3 仗平均；逐季；EXP-11 簡化模型換走輸頭馬等級

## 結果（2020/21 → 2026/27，5,161 場／56,060 匹）
| 數值 | 場內 AUC | 贏 M 季數 |
|---|---|---|
| M 輸頭馬秒數（現行概念） | **0.6604** | — |
| D0 對標準 | 0.6362 | 0／7 |
| D1 ＋真步速修正 | 0.6434 | 0／7 |
| D2 ＋當日場地快慢 | 0.6588 | 2／7 |
| D2W ＋負磅換算 | 0.6535 | 1／7 |

簡化模型 5,206 場（對 M）：D2 Gold +0.06／Good +0.04（打和）；D2W Gold −0.17／Good −0.21；D1 Good −0.71 [−1.29, −0.08]；D0 Good −0.54。
頭二選有中：M 76.51%，D2 76.43%，D2W 76.30%。

## 結論
1. 步速修正真係有用：D0 → D1 → D2 每步都升（0.636 → 0.643 → 0.659）。但做足步速＋當日場地快慢之後，**只係追返輸頭馬秒數**（0.659 vs 0.660）
   —— 輸頭馬距離本身已經自動扣走咗嗰場步速同場地，所以「真步速修正偏差」同現行數值等價，冇改善。
2. 負磅換算喺呢個版本反而令 AUC 跌（0.659 → 0.654），同 EXP-11 表現數字（扣埋對手強弱）入面升唔同 ——
   未搵到原因，記錄做未解。
3. 喺時間類數字入面，**只有扣賽事效應（連對手強弱）嘅表現數字贏過輸頭馬**（EXP-11 0.6688）。

**決定**：REJECT（真步速修正唔贏輸頭馬）；MEASUREMENT（k = 0.633）

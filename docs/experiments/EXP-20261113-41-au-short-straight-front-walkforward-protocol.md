## 候選 W1（唯一一個 arm）

- 規則同 EXP-20261113-23 L2 一樣，**只改幅度**：
  - 前置 = 跑法標籤（`running_style_line`，賽前）含「前領」或「跟前」。
  - 短直路 = 場地直路 < **375m**（L arm 已用嘅門檻：判決窗場次直路中位數）。冇幾何 → 唔加。
  - `ability' = ability + β_t`（前置 × 短直路），其他馬唔變。
- **β_t 由 walk-forward 擬合**（mode `walk_forward_oos`）：對每個賽日 t，只用 **t 之前** 嘅賽日：
  逐匹 logistic `入前三 ~ a + b·(ability − 場均 ability) + c·前置短直路`（Newton，最多 50 次），β_t = c ÷ b，夾喺 [0, 10]。
  b ≤ 0 或者唔收斂 → β_t = 0。
  頭 **20 個賽日** warmup：β = 0（候選 = baseline）。
- 預先寫死：門檻 375、warmup 20、夾 [0, 10]、模型式。**唔准改**。

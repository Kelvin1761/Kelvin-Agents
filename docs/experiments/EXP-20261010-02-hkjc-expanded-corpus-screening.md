# EXP-20261010-02 — HKJC 擴大語料（1,797 場）訊號篩選

- **日期**：2026-10-10；平台：HKJC
- **狀態**：**篩選（screening），唔係判決**。結果只用嚟揀邊個候選值得做正式測試。
- **工具**：`hkjc_reflector/scripts/hkjc_expanded_corpus.py`（build／screen／incremental）
- **語料**：`HKJC_Race_Results_Database` 全部賽事，2024-09 至 2026-10-07，1,797 場、22,492 匹次。
  每匹馬嘅特徵只用**賽日之前**嘅賽事；同日賽事互相睇唔到（逐日更新）。
  賠率只存喺 `market_win_odds` 做 benchmark，**唔入任何模型**。
- **重建唔到**：段速分段、晨操、賽績線對手強度、官方評分（只有班次評分帶）、配備。

## 方法

1. **無條件 cohort**：實際上名率 vs 預期（3 / 馬匹數）。
2. **條件篩選**：同場 softmax conditional logit，核心特徵 = 近三仗名次百分位、近三仗輸距、
   歷史上名率、騎師／練馬師 as-of 上名率（EB k=20）、檔位百分位、同程上名率、負磅 vs 頂磅。
   前 70% 日期 fit，後 30% 日期測（out-of-sample）；ΔLL 用場次 bootstrap 200 次出 95% CI。
   核心模型 out-of-sample 場內 AUC **0.7143**。

### 「可原諒」點樣做先啱

同一批 19,740–20,268 匹次比較：

| 版本 | 近三仗名次 AUC |
|---|---:|
| 原始（照計） | 0.6773–0.6803 |
| 剔走「嚴重」藉口仗（醫療＋走位混埋） | 0.6571 |
| 只剔走「走位受阻」仗 | 0.6743 |
| 只剔走「醫療」仗 | 0.6621 |

**剔走成仗會變差**：有藉口嘅仗仍然有資訊（成日受阻嘅馬本身有問題）。醫療事故（流鼻血、
心律不正、跛行）**唔應該原諒**。正確方向係「走位受阻嘅差仗**部分**原諒」，訊號細但
CI 唔跨零。輕微藉口字眼（搶口、斜跑、外閃）係噪音。

## 結論（篩選，唔係判決）

- **值得正式測**：
  1. 早段位置／跑法（同 race_shape E3 同一機制）。
  2. 走位受阻差仗嘅部分原諒（Phase 4e-1 仗次可靠度，用 trouble 字典，排除醫療）。
- **cohort 差距被核心特徵食晒，唔值得做獨立維度**：換騎分類、升降班、長休、首次增縮程、
  轉倉、體重變化、練馬師近況。（[[au-cohort-gap-is-not-a-gain]] 同一個教訓。）
  - 換騎：一刀切 −1.5 嘅**方向**仍然要審（升級／換返熟手唔應該扣），但條件效應細，
    屬 §7 合理性修正而唔係新訊號。
- 首次增程嘅「早段慢、尾段快」假設要逐仗分段時間，擴大語料冇；要喺 362 場全模型語料做。

## 附：賽日偏差診斷（Kelvin：「前置／內疊日表現好，後追／外疊日差好遠」）

語料：harness baseline（origin/main，PIT），29 個賽日（剔走 04 月 speed_score 死日），
每日「實際偏差」= 該日頭三名平均（檔位百分位 − 全場平均）／（實際首段位置 − 全場平均）。

| | 數值 |
|---|---:|
| corr（每日 Good，內檔偏差） | **−0.616** |
| corr（每日 Good，前置偏差） | 0.021 |
| 內檔有利日（中位數以下）Good | **32.8%** |
| 外檔有利日 Good | **15.8%** |
| 模型頭三選平均檔位百分位 | **0.299**（全場 0.496） |

**解讀**：賽日之間嘅波動嚟自**檔位**，唔係跑法。模型結構上大幅押注內檔（race_shape 27.4%，
當中檔位分佔大頭），內檔有利日押中、外檔有利日押錯。呢個同 [[hkjc-race-day-consistency]]
係同一個問題，而家知道機制。

**下一步（入 race_shape 維度審計，逐個預先登記）**：
1. 結構性傾斜幅度：量「模型頭三選檔位百分位」vs「實際上名馬檔位百分位」嘅長期差距，
   睇係咪押過頭（實際上名馬平均檔位百分位要計埋）。
2. 賽前預測當日檔位偏差（rail 位置、跑道、季節）—— 之前量過檔位重要性唔跨季穩定（r 0.11），
   要先證明有預測力。
3. 報告層警示：已跑場次顯示外檔有利時，dashboard 標示。
4. 唔准重做同日偏差入分（EXP-20260928-04 REJECT）。

| 場地 | 1–4 檔 | 5–8 檔 | 9+ 檔 |

**解讀**：檔位效應真實（內外差約 10pp，直路相反，模型嘅直路表已經反轉），但模型揀馬比
實際上名馬內好多 —— 檔位（場內 AUC 約 0.56）佔綜合分約 15%（27.4% × 沙田 55%），而
近績（AUC 0.68）只佔 4.9%。即係 [[hkjc-leaf-weight-accuracy-mismatch]] 嘅同一個問題，
亦係「外檔日 Good 減半」嘅機制。

**處理**：屬 Phase 3 外層權重（計劃次序最後）。必須用 Stage 4 v3 walk-forward
（每個賽日只用之前賽日 fit），唔可以喺呢 286 場 in-sample 調。舊 refit（EXP-0902-03、
0928-06/07）喺細語料同 v2 下失敗，今次條件唔同：擴大語料做內層、v3 全紀錄判決。

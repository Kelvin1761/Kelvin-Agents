# EXP-20261124-71：NBA 大細盤精選嘅收市價（CLV）—— 冇真 edge 嘅證據（只量度）

- **日期**：2026-11-24 · **平台**：NBA · **性質**：診斷量度；冇改任何 code、冇判決。
- **起因**：EXP-20261124-70 發現 `p_final` 喺去水去得啱嘅市場價之上冇加到資訊。用一個獨立方法核實：精選 21:00 揀嘅注，市場收市前有冇向我哋嗰邊移？CLV 比 ROI 穩定好多，幾十注已經睇到方向。

## 做法（`patches/nba_featured_clv/clv.py`）
- 精選 = 每場第一個開波前 production `selection_obs.diagnostics.featured`（v1，target_date ≥ 2026-11-11）。
- 21:00 去水 P(我哋嗰邊) = 精選記錄嘅兩邊價比例去水；收市 = 同一條 O/U 線最後一個開波前 `ou_two_way` 報價去水。CLV = 收市 − 21:00（pp）。
- 對照：全部 O/U 線由當晚第一個報價到收市，去水 P(大) 嘅平均漂移。
- 按日 bootstrap 2,000 次。

## 結果
| | n | 平均 CLV |
|---|---|---|
| 精選（同一條線有收市價） | 44（13 日） | **+0.88pp [−0.61, +2.09]**；52% 正、20% 零 |
| 其中 AST／PTS | 34／10 | +0.76／+1.30 |

- 精選全部係細，扣除 under 嘅自然漂移，淨 CLV 約 **+0.6pp，CI 跨零**。
- 23 注收市時冇同一條線：收市主線向我哋嗰邊移 **2**、反方向 **8**、13 個盤收咗／睇唔到。
- CLV > 0 嘅注中 57%（13/23），≤ 0 嘅中 52%（11/21）—— 樣本太細，唔解讀。

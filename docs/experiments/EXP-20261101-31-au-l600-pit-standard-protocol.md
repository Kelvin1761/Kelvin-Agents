## 候選（標準由數據 fit → `walk_forward_oos`：每個目標賽日只用之前嘅賽事 fit）

**S**：情境標準，直接沿用 live `full_time_speed.ContextStandard`（同一套類別、penalty、IRLS 穩健權重，唔改任何數）：

```
y   = log(L600 原秒 / 600)
x   = 截距、log(距離/1400)、平方，加 one-hot：場地、地況、場地×距離段(400m)、場地×地況、班次（班次只做估計用）
par = 預測值（班次用共同水平，即高班賽事跑得快仍然算快） + 同日場地修正
同日場地修正 = 同場地同日其他賽事殘差中位數，clip ±0.05，× n/(n+3)，要 ≥3 場先用
新 delta = 原秒 − 600 × exp(par)
```

fit 只用可靠賽事、`date < 目標賽日`、至少 100 場。新 delta 之後一切照現行：`own = delta + margin × 0.17`、近期加權 0.8^k、
場內 z、60 − 20z。

**S0**（ablation）：同 S 一樣但冇同日場地修正。

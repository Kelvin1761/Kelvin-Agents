# EXP-20261113-02 — HKJC 逐段段速對馬會標準篩選

- 日期：2026-11-13
- 平台：HKJC
- 決定：**診斷**（決定落 EXP-20261113-03 揀邊個做候選）

## 問題

Kelvin：「we are just using L400? hkjc have all sections speed … adjust the number with the 場地標準時間」。

現行段速維度入分嘅部分：輸頭馬差距（等級）、L400 原始走勢（L400 絕對值＋趨勢）、能量、分段形態。**冇一項係逐段對標準**。
「對馬會標準（未入分）」（EXP-20261112-09 `std_pace`，全程對標準＋負磅換算）只顯示，喺 forward shadow `std_pace_shadow`。

## 方法

`patches/hkjc_section_screen.py`。449 場引擎回放（labels_final）。每匹近 6 仗（賽績檔自己嘅分段），每段減馬會標準分段
（今仗班次；冇就嗰仗班次），負磅按段長換算到今仗，1/k 加權，最少 2 仗。模型之上係數 = 入頭三 ~ 場內 z(綜合分) + 場內 z(特徵)，場次 bootstrap 1000。

## 解讀

- **後段（L400／L800／後勁）模型已經食晒**：同 speed_score ρ 0.5–0.56，模型之上冇增量。
- **前段同全程對標準係模型冇嘅資訊**：第一段、L400 之前各段同 speed_score 幾乎零相關（ρ −0.08／+0.01），但模型之上係數全正。
  即係「每一段都對標準」嗰度，有用嘅係前段，唔係再細分後段。
- 表現數字（完成時間，賽果庫）仍然係最強單一數值。
- 係數 ≠ 排名改善（EXP-24：殘差訊號經常被其他組件抵銷），要用 arm 驗證 → EXP-20261113-03。

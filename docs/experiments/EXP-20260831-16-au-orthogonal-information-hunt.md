## 三、段速復活（本次唯一有功效嘅候選家族）—— REJECT

`sectional_score` 而家零權重，AUC 按距離**單調遞增**（0.5104 → 0.5169 → 0.5549 →
0.5754），所以「距離連續縮放」版碰**每一場**，功效足夠。

| 候選 | 判決 | gold dev | gold terminal | CI |
|---|---|---:|---:|---|
| A 無條件 +0.3·z(sect) | REJECT | +0.0016 | −0.0040 | [−0.0120, +0.0040] |
| B +0.3·w(dist)·z(sect) | REJECT | +0.0008 | −0.0040 | [−0.0100, +0.0000] |
| B +0.8·w(dist)·z(sect) | REJECT | +0.0008 | **−0.0120** | **[−0.0220, −0.0040]** |
| C 只 >1400m +0.5·z(sect) | REJECT | +0.0031 | −0.0020 | [−0.0060, +0.0000] |

k=0.8 嘅 CI **不跨零** → 顯著**有害**，唔係功效不足。

### 但唔係因為重複 —— 段速好正交

場內 z 相關（17,838 匹）：vs **ability 只 +0.1813**；vs form_score +0.1849、
pace_figure +0.1245、rating +0.0580、trial **−0.0444**。

### 真瓶頸：48.8% 匹馬坐喺 60 地板

| | |
|---|---:|
| 坐地板 60（冇 PI 數據）| **8,707 / 17,826 = 48.8%** |
| 全場都有段速數據嘅場次 | **93 / 1,780 = 5.2%** |
| 段速 AUC（全部）| 0.5328 |
| 段速 AUC（全覆蓋場次）| **0.5624** |

所以場內 z **混咗「冇數據」同「跑得慢」** —— 呢個就係「訊號真、正交、但加落去有害」
嘅機制。限制喺全覆蓋場次加（候選 D/E）**唔判得到**：只 5.2% 場次，terminal CI
全部 `[+0.0000, +0.0000]` → **UNRESOLVABLE**（契約 §6）。

PI 覆蓋係結構性受限（`entry["pi"]` 64.5%，其中 7.0% 係首戰完全冇往績）。
要動段速就要先解決覆蓋，而 [[au-pf-coverage-unlock-needs-refit]] 嗰次同型解鎖
輸咗三次 —— 所以覆蓋解鎖本身要獨立論證，唔可以當作順手。

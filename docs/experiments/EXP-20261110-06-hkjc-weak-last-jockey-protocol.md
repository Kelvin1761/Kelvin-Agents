## 定義（凍結）

- 「上仗」= 呢匹馬最近一次有完成名次嘅賽事。
- **騎師入位率** = 該騎師喺賽日前 365 日內嘅入前三率；**最少 100 次策騎**先評級，唔夠就當「未評級」（唔算弱）。
- **弱騎師** = 賽日當日，喺所有已評級騎師入面，入位率排**最低三分一**（按騎師計，唔係按策騎次數計）。
  評級用**今仗賽日**之前嘅資料，量度上仗騎師而家嘅級數（全部喺今日之前）。
- 「頂級騎師」沿用 EXP-20261027-12：賽日前 365 日勝出數頭 6 名。

| ID | 定義 |
|---|---|
| J1 上仗弱騎師＋換人 | 上仗騎師係弱騎師，而且今仗騎師唔同 |
| J2 J1，今仗唔係頂級騎師 | J1 而且今仗騎師唔係頂級 —— 排除同 P1 重疊，淨係睇「上仗被低估」 |
| J3 J1，上仗跑差 | J1 而且上仗名次 ≥ 6 —— 機制版本：差嘅賽績怪落騎師身上 |

方向：三個都預先登記為 **+**（假設方向），唔由 D 決定。D 方向相反就照報。

## 判決（凍結）

1. **leakage**：特徵用到嘅紀錄日期一律 < 賽日；報告同日／之後行數要 = 0。
2. **L2 主判決**：J1–J3 一齊做 Holm（單邊，方向 +）。Holm 後 p < 0.05 **而且** M 段 pattern 馬 ≥ 80 匹次 → overlay 候選。
3. **J2 決定有冇新嘢**：如果只有 J1／J3 過而 J2 唔過，結論係「效應嚟自今仗換上好騎師」，即係 P1 嘅重複；
   P1 已經喺 EXP-20261027-13 walk-forward REJECT，**唔會再開幅度實驗**。
4. L1 只作佐證。
5. 唔准事後改門檻（100 次、三分一）、分層或窗口去救。
6. 無論結果點，**live 模型唔郁**；過閘都只係下一個實驗嘅輸入。

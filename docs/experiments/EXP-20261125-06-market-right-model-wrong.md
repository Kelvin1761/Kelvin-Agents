## 定義

每場：市場排名 = SP 由低到高；模型排名 = ability 由高到低；「入位」= 頭三。
- **A（市場啱、模型錯）**：市場頭二、模型排第 4 或之後、而入咗位。
- **C（對照）**：市場頭二、模型都排頭三、入咗位。
- **M（模型啱、市場錯，鏡像）**：模型頭二、市場排第 4 或之後、入咗位。
- D = 市場頭二兼模型 ≥4（唔理入唔入位）；MD = 模型頭二兼市場 ≥4。

## 3. 早更價 vs SP：市場係咪臨跑先「學到」嘢？

入頭三 log-loss 階梯（walk-forward：4 個時間塊，前面訓練、下一塊測試，29,883 匹；每個 arm 都帶 log 匹數；差距 = 賽日 bootstrap 95% CI）：

| 階 | ll | 由上一階改善 |
|---|---|---|
| 均一（flat） | 0.6198 | |
| 模型（ability 校準） | 0.5514 | 0.0684 [0.0651, 0.0720] |
| **重擬全部現有輸入**（同一批 leaf＋中性旗號＋context，線性） | 0.5468 | **0.0045 [0.0031, 0.0060]** |
| 早更價 | 0.5148 | **0.0320 [0.0290, 0.0348]** |
| SP | 0.5048 | **0.0101 [0.0082, 0.0118]** |

模型 → SP 嘅總距離（0.0466）分三份：
- **約 10%：睇到但用得唔好**（輸入已經有，權重／形狀問題；GBM 重擬仲細，0.0016 跨零）
- **約 69%：市場有、我哋輸入冇**（朝早價已經知道）
- **約 22%：朝早之後先到（late money）**
- 另外：早更價 + 重擬輸入 對淨早更價 = −0.0003 [−0.0011, +0.0005] → **我哋嘅輸入對朝早價冇任何額外資訊**。

即係市場嬴模型嘅優勢，**約 78–83% 朝早已經喺個價度**（用 per-runner logistic 計 83%），唔係臨跑先嚟。A 組 68% 朝早已經係市場頭二；A 同 D 唔入位嗰批嘅落飛幅度一樣（中位 −13%），所以**落飛本身分唔開入唔入位**。M（模型啱）嘅典型係**飄**嘅馬（中位 +20%，64% 飄 >10%）。

**運氣下限**：連 SP 都仲剩低均一 log-loss 嘅 81%。市場頭二都有 37% 唔入位。呢部分喺現有公開資訊之下係**不可預測**。

## 4. 「睇到但冇用」vs「睇唔到」：組別殘差

`signal_gaps.py`：殘差 = 實際入頭三 − 校準機率（前半段擬合）。**模型殘差 ≠ 0 而市場殘差 ≈ 0 = 市場睇到、模型用得唔夠**。（in-sample，live 110 日；後半段單獨列出睇穩唔穩。）

| 組別 S | 覆蓋 | 模型殘差 pp [CI] | 後半段 | 市場殘差 pp [CI] |
|---|---|---|---|---|
| 試閘分 z≥1 | 9.4% | **+5.05 [+3.69, +6.70]** | +4.46 | +0.19 [−1.03, +1.66] |
| 備戰分 z≥1 | 17.0% | **+4.56 [+3.49, +5.59]** | +5.55 | −0.17 [−1.15, +0.80] |
| 騎師分 z≥1 | 17.4% | **+3.49 [+2.00, +4.89]** | +4.91 | −0.54 [−1.89, +0.64] |

讀法（**部分係推測**）：
- **睇到但冇用好**：試閘、備戰、騎師、練馬師、休後狀態（freshness 曲線）—— 數據已經喺 leaf 度，市場正確定價，模型權重偏細／形狀唔啱。但第 3 節講咗：成批加埋只值 0.0045 nats（模型→SP 距離嘅 10%），而且**呢啲市場已經定晒價**，改好佢都唔會令模型贏市場，只係令模型追近市場。
- **市場睇到、我哋輸入冇**（69% 嘅大頭）：A 組特徵係「冇證據」（中性 leaf、初出、冇段速、跑法未知）。市場對呢類馬有我哋冇嘅資訊 —— **推測**：試閘錄影／試閘時間（`timing_trial_600m_avg_speed` 語料 0% 有值，EXP-20261016-75）、血統／買價、馬房口風、上仗競賽主任報告（受阻、出閘慢）、配備改動、騎師轉換嘅含意。呢部分要新數據源先有得做。
- **late money**（22%）：只可以由市場本身得到；賠率唔准入模型 → 呢部分**我哋原則上唔追**。
- **運氣**：SP 之後仲剩 81% 不確定性；D 入面入唔入位基本係市場機率擲骰。

## 6. HKJC 簡版（回放 2020-09 → 2026-11）

同一個形狀：D 實際 47.1% ≈ 市場預期 48.8%，模型預期 27.5%；模型 ll 0.4973 vs 市場 0.4695。A vs C：A 喺穩定性、近績、一致性、段速全部低（−1.0 至 −1.5 SD），初出 +0.42 SD。D 入面入位 vs 唔入位：只有匹數（−0.16）、初出（+0.12）、信心分（−0.10）顯著。殘差組別：騎師 z≥1 +1.53pp、練馬師訊號 +1.48pp（市場殘差 −1.0 —— 市場對熱門騎練反而略高估）；級數、一致性、穩定性、近績 z≥1 **被模型高估** −1.6 至 −2.3pp。注意：回放唔係 live，而且係全期 in-sample 校準；只做方向參考。

## 結論

- 「市場揀中、模型揀唔中」AU 每場平均 0.31 次，比反過嚟（0.17）多一倍。分歧嗰陣結果貼市場機率，唔係市場好彩。
- 模型→市場距離：**~10% 係我哋已有輸入用得唔好**（試閘／備戰／騎練／休後狀態，市場已定價），**~69% 係市場朝早已知但我哋冇嘅資訊**（集中喺冇證據馬），**~22% 係朝早後先到嘅錢**（唔准追）。SP 之後仲有 81% 不確定性 = 真運氣。
- 我哋嘅輸入對朝早價冇額外資訊（−0.0003 [−0.0011, +0.0005]）。
- 冇改任何模型 code。H1 功效夠、H2／H3 邊緣、H4 預設唔開。下一步係 Kelvin 揀要唔要預先登記 H1（用新賽日判），同埋決定 H4／H5 嘅新數據源值唔值得搵。

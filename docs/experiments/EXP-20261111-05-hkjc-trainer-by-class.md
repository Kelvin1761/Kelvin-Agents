# EXP-20261111-05 HKJC 練馬師分班次表現（screening）

- **日期**：2026-11-11（假設同判決規則喺睇結果之前寫）
- **平台**：HKJC
- **觸發**：Kelvin 問「HKJC 旺財有冇睇練馬師唔同班次表現？」—— 冇。live 練馬師訊號只有兩季整體實績、
  騎練組合、練馬師同程（`live_priors.GENERAL_PRIOR_FILES`）
- **假設**：練馬師喺「今場班次」嘅上名超額（相對佢自己整體）係穩定嘅練馬師特質，而且喺
  騎師整體＋練馬師整體＋練馬師同程＋練馬師場地之上仲加到排序力
- **搜索過嘅舊記錄**：冇練馬師 × 班次。最近嘅係 EXP-20260905-03（練馬師 × 場地，screening ✅ 但引擎 A/B
  五個 arm 冇一個過閘）、EXP-20261018-03（騎練加減項審查）、EXP-20261109-02（級數分 365 日窗，REJECT）
- **改到嘅檔案／組件**：**冇。純量度**，冇改 production code

## 配置
- **baseline**：origin/main `7c8775b8`（冇改）
- **candidate**：只喺 harness 砌特徵 `t_dc` = EB(練馬師, 班次組) 超額 − EB(練馬師) 超額

## 方法（預先定）
- **語料**：`pit_backtest.load_all_rows()`（同 PIT priors 同一份；有 `RaceClass`）
- **班次組**：C5／C4／C3／C2／高班（C1＋G1／G2／G3）／其他（Griffin、Unknown）
- **期望值**：逐場「上名數 ÷ 出賽數」，所以馬匹數同班次本身嘅上名率差異由期望值食走
- **walk-forward**：逐個賽日只用 `Date < 賽日` 嘅行估先驗；EB shrink k=100（同 `JT_RATING_PARAMS`）
- **out-of-sample**：2025-09-01 起嘅賽日
- **combiner**：logistic，配對 bootstrap 400 次、按場次重抽（同 EXP-20260905-03 一樣，數字可以直接比）
- **市場對照**（只做對照，唔係特徵）：加落場內正規化 1/賠率 之上，睇市場係咪已經食咗

## 判決規則（screening，只開一次）
- **PASS（值得做引擎 A/B）**：`t_dc` 加落 (騎師整體, 練馬師整體, 練馬師同程, 練馬師場地) 之上，
  Δ AUC 95% CI 下界 > 0，**而且**跨季 r（24/25 → 25/26，同一 (練馬師, 班次組) ≥30 仗）CI 下界 > 0
- 任何一樣唔過 → **REJECT（screening）**，唔開引擎 A/B
- 唔換班次分組、唔換 k、唔換 OOS 窗去救
- PASS 都唔等於改善：EXP-20260905-03 練馬師場地 screening ✅ 但引擎 A/B 全部唔過閘

## 數據
- **語料**：`load_all_rows()` 23,253 行 / 1,887 場 / 194 賽日（2024-09-08 → 2026-11-08）
- **OOS**：2025-09-01 起 12,935 行 / 1,040 場 / 106 賽日
- **覆蓋**：練馬師×班次組 有記錄 99.8%、≥30 仗 95.7%、≥100 仗 81.2% —— 樣本唔係問題
- **班次組**：C4 11,024／C3 6,542／C5 3,239／C2 1,326／高班 942／其他 180

## 結果

### 判決項
| 測試 | Δ AUC [95% CI] | |
|---|---|---|
| 練馬師同程加落 (騎師, 練馬師)（**陽性對照**，live 已有） | +0.0013 [+0.0002, +0.0025] | ✅ |
| 練馬師班次加落 (騎師, 練馬師) | −0.0000 [−0.0002, +0.0001] | ➖ |
| 班次加落同程之上 | −0.0000 [−0.0001, +0.0001] | ➖ |
| **班次加落同程＋場地之上【判決】** | **+0.0000 [−0.0000, +0.0001]** | ➖ |
| 班次加落市場之上（對照） | +0.0000 [−0.0001, +0.0002] | ➖ |

單獨 AUC：騎師 0.6024、練馬師 0.5531、場地 delta 0.5240、同程 delta 0.5045、**班次 delta 0.4987**（低過 0.5）。

陽性對照重現到 EXP-20260905-03 嘅同程 +0.0010 同場地單獨 AUC 0.5211，所以 harness 接通咗；班次 delta 係真零。

### 分班次組（加落同程＋場地之上，bootstrap 200）
| 組 | 場數 | Δ AUC [CI] |
|---|---:|---|
| C5 | 146 | +0.0007 [−0.0014, +0.0029] |
| C4 | 483 | +0.0003 [−0.0001, +0.0009] |
| C3 | 289 | +0.0000 [−0.0004, +0.0005] |
| C2 | 67 | +0.0022 [−0.0029, +0.0067] |
| 高班 | 47 | −0.0029 [−0.0078, +0.0014] |

冇一組 CI 離開零；冇「只喺高班／只喺低班有用」嘅位可以救。

### 穩定性（(練馬師, 班次組) ≥30 仗，delta 相對同期練馬師整體）
| | 格數 | r [95% CI] |
|---|---:|---|
| 跨季 24/25 → 25/26 | 71 | **−0.027 [−0.336, +0.301]** |
| 拆半（單雙賽日） | 80 | +0.091 [−0.121, +0.289] |

對比練馬師×場地：跨季 r +0.504、拆半 +0.639。練馬師喺邊個班次「特別好／特別差」**唔係一個會延續嘅特質** ——
上季喺 C3 跑得好嘅練馬師，今季喺 C3 冇傾向繼續好。

相關性（Spearman，OOS）：`t_dc` 對練馬師整體 −0.300（EB shrink 嘅機械相關）、對同程 +0.151、對市場 +0.023。

## 檢查
- **leakage-audit**：PASS —— 所有先驗只用 `Date < 賽日`；期望值用嘅「場內上名數 ÷ 出賽數」係結構常數（一場永遠 3 個位，
  細場 2 個），唔帶個別馬賽果；賠率只做對照，冇入特徵
- **golden_scoring**：冇郁（冇改 code）
- **data_contract**：不適用
- **退步**：冇（冇改 code）

## 結論
練馬師分班次表現喺 HKJC **冇訊號**：加落現有騎練訊號之上 Δ AUC 0.0000，單獨 AUC 0.4987，
而且根本唔穩定（跨季 r −0.027）。失敗唔係因為樣本薄 —— 95.7% 出賽行有 ≥30 仗嘅格；係「練馬師 × 班次」
呢個切法本身冇延續性，所謂「呢個練馬師擅長 C3」只係噪音。所以唔開引擎 A/B。

未測（另一個假設，要另開記錄）：「練馬師帶馬升／降班」嘅成績（班次**變動**，唔係班次本身）。

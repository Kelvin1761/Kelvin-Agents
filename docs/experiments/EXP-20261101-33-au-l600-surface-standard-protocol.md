## 候選（`walk_forward_oos`：每個目標賽日 D 只用 date < D 嘅往績 fit）

**SH**：

```
y = log(個體 L600 / 600)
y = μ + 馬匹效應 + 場地效應 + f(距離) + 地況效應 + 殘差
f(距離) = a·log(d/1400) + b·log(d/1400)²
交替最小二乘 30 次：
  馬匹效應 ← Σ(y − 其他) / (n_馬 + 1)
  場地效應 ← Σ(y − 其他) / (n_場地 + 20)     （每次之後置中）
  μ、f、地況 ← 對 y − 馬匹 − 場地 做 OLS
賽事殘差 = 嗰場各馬 (y − 馬匹效應 − 預測) 嘅中位數
par  = μ + 場地效應 + f(距離) + 地況 + 同日修正
同日修正 = 同場地同日其他賽事殘差中位數，clip ±0.05，× n/(n+3)，≥3 場先用（同 EXP-31）
新 delta = 賽事原秒 − 600 × exp(par)，捨入 3dp
```

par 唔包馬匹效應（= 平均馬喺嗰場條件下嘅標準）。之後一切照現行（own = delta + margin × 0.17、近期加權 0.8^k、場內 z）。
fit 至少要 100 場賽事。

**G**（ablation）：同 SH 一樣但**冇場地項**（只有路程、地況、同日修正）—— 答「純路面場地項本身有冇用」。

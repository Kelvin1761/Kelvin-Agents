# EXP-20261111-06：S 逐項公式（三分拆法、節奏、籃板前後場、助攻、罰球）—— 全部唔採用

- **日期**：2026-11-11
- **平台**：NBA
- **起因**：Kelvin 想得分、籃板、助攻、三分各自有專屬公式。而家只有得分係拆開計，其餘三項都係「每分鐘產出 × 時間 × 對手」。
- **冇改任何上線 code。**

## 做法
- 語料：2025-26 例行賽＋2026-27 至 11-09 嘅球員-場次（19,963；之前 ≥5 場、基本時間 ≥15 分鐘），特徵只用比賽日之前嘅比賽。
- **用實際上場時間**計預測均值，淨係量每分鐘產出率；指標 = Poisson deviance，配對、按日 cluster bootstrap。
- dev = 2025-26 至 02-08；holdout = 之後；跨季 = 2026-27。參數只喺 dev 用格點揀。
- 基準 = 現行 S 嘅產出率（半衰期 20、收縮 30 分鐘、對手失分收縮 10 場），**但只用今季比賽**（語料冇 2024-25）。

## 結果 1：研究語料（Δ deviance，負 = 好）
| 項目 | 改動 | dev | holdout | 今季 |
|---|---|---|---|---|
| 三分 | 拆「每分鐘出手 × 收縮命中率（36%，100 次）」 | −0.039 | −0.012 [−0.022, −0.003] | −0.088 |
| 三分 | 同上，對手調整改用失三分出手 | −0.039 | −0.012 | −0.088 |
| 全部 | 節奏（兩隊回合數） | ±0.000 | −0.0006…−0.0016 | ±0.000 |
| 全部 | 節奏（大細盤總分） | ±0.001 | ±0.001 | 三分 +0.003 |
| 籃板 | 拆前場（自己隊射失）／後場（對手射失） | +0.006 | **+0.015** | +0.004 |
| 助攻 | × 自己隊入球數 | 擬合指數 = 0 | — | — |
| 得分 | 罰球部分改用對手送罰球 | +0.0006 | **+0.0015** | −0.0015 |

三分收縮強度 K 50–1600 結果差唔多（dev 揀 200）。

## 結果 2：用上線 S 嘅計法再測三分（今季 9 日、2,396 條有盤口嘅三分腿）
研究基準只用今季比賽，但上線 S 季初會撈埋上季（權重 0.25）。所以喺 `nba_engine.model` 嘅原本計法入面直接換三分公式：

| | log-loss | Δ 對 S [95% CI] |
|---|---|---|
| 市場 | 0.4815 | |
| S 現行 | 0.4778 | |
| S 三分拆法 K=100 | 0.4776 | −0.0002 [−0.0049, +0.0041] |
| K=200 | 0.4783 | +0.0005 [−0.0049, +0.0054] |
| K=400 | 0.4792 | +0.0013 [−0.0047, +0.0068] |

- 10 月（上季數據佔多）−0.005、11 月 +0.001 至 +0.004：收縮只係喺樣本少嗰陣有用，而上季數據已經做咗同一件事。
- **一個方法錯誤**：第一次用「新／舊均值比例」套落上線 S，得出 +0.014（變差）。因為兩個基準唔同，比例會重複修正；呢個數唔可信，已經用引擎原本計法重做。

## 檢查
- **leakage**：特徵全部比賽日之前；總分盤係 ESPN 賽前盤（研究用，上線冇呢個欄）。
- **ablation**：每項分開量。
- 限制：研究語料冇 2024-25，所以上季嘅基準弱過上線 S；引擎測試只有 9 日。

## 結論
五個逐項改動冇一個值得上線：
- 節奏、助攻 × 隊友入球：冇作用。對手失分調整已經包咗大部分節奏。
- 籃板拆前後場、罰球改用對手送罰球：更差。
- 三分拆法：研究語料好明顯改善，但喺上線計法入面打和 —— 改善嚟自「樣本少時穩定命中率」，上線已經用上季數據做咗。

**決定**：REJECT（全部）。三分拆法係「冇效果」，唔係「有害」；如果日後拎走上季數據嘅混合，要重新考慮。
**提示**：之前 EXP-20261111-02 已經量到，產出率誤差大部分係單場運氣。逐項公式嘅空間本身細；上場時間（EXP-20261111-05 forward 中）同當日正選名單先係大槓桿。

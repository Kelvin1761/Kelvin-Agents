## 但係：模型喺入面嘅貢獻係**零**

dev 揀 k 一路揀到邊界（k=8 仲上緊），即係「盡量重用市場」。所以直接掃混合比重
`w·z(模型) + (1−w)·z(市場)`：

| w（模型佔比） | 場內 AUC |
|---:|---:|
| **0.0（純市場）** | **0.7332** |
| 0.1 | 0.7331 |
| 0.2 | 0.7294 |
| 0.5 | 0.7158 |
| 1.0（純模型） | 0.6665 |

**最佳 w = 0.0。** 加任何模型比重都令 AUC 單調下跌。即係話：市場價已經包含晒
我哋模型嗰堆訊號，而且包含得更好。呢個唔係「模型 + 市場 > 市場」，
係「市場 ≥ 市場 + 模型」。

## 所以呢個決定係咩

**唔係「要唔要更準」，係「Wong Choi 要唔要變成一個跟盤工具」。**

* 要指標靚 → 直接排市場價，Gold +2.36pp、Pass +3.35pp 即刻到手。
* 但排名一旦等於市場排名，**落注就冇任何 edge** —— 你會喺市場價買市場熱門，
  而 racenet SP 抽水 19.8%（[[au-takeout-beats-the-edge]]）。指標升，
  期望值反而更差。
* 而且 `AGENTS.md` 寫住「賠率／市場價唔准做隱藏 proxy，除非個 methodology
  明文寫住佢係模型一部分」—— 即係要 ship 就要先改 methodology，唔可以靜靜加。

## 兩條可以行嘅路（都要 Kelvin 拍板）

1. **顯示層用，排名層唔用。** 報告加一欄「市場排第幾」同「模型 vs 市場分歧」。
   分歧本身係有用資訊（[[au-market-move-signal-is-asymmetric]] 已經量過飛起
   >25% 入位率 32%），而且完全唔影響模型獨立性。
2. **明文改 methodology，市場入模型。** 咁 Wong Choi 就由「獨立評估」變成
   「市場 + 微調」。指標會靚，但要接受佢係跟盤，唔好再攞佢嘅 Gold/Pass 當
   「我哋捉到市場捉唔到嘅嘢」。

我建議 (1)。(2) 嘅指標升幅係真嘅，但佢買唔到 edge。

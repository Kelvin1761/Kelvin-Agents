# EXP-20261101-32 診斷：場地 L600 標準有大約四分三係「嗰度啲馬質素」，唔係路面快慢

- **日期**：2026-11-01；**平台**：AU；**類型**：只量度，冇改模型。
- **用戶問題**：EXP-20261101-31 新標準令 leaf 準咗但排名差咗 —— 「有個標準時間應該更能反映馬匹能力」，點解唔得？
- **腳本**：`scratch/au_l600_standard_dig_20261101.py`（數據：EXP-31 賽事表 + 全部 Formguide 逐駒往績，
  96,844 匹次／14,458 匹馬；個體 L600 = 賽事原秒 + 輸距 × 0.17；先除路程曲線同地況）。

## D1 場地效應拆解（112 個場地，每個 ≥150 匹次、≥50 匹次嘅馬喺其他場地都跑過）

同一匹馬喺唔同場地跑 → 馬匹固定效應模型估「純路面快慢」（within）。直接平均每個場地 → 「pooled」，
即係任何按場地分嘅標準（舊手寫表、EXP-31 情境標準）學到嘅嘢。

| | 數值 |
|---|---|
| 場地效應 SD：pooled | **0.96 秒** |
| 場地效應 SD：within（純路面） | 0.65 秒 |
| 對場地獎金水平（log10 中位獎金）斜率：pooled | **−1.72 秒／10 倍獎金** |
| 同上：within | −0.42 秒 |
| 同上：被吸收部分（pooled − within） | **−1.30 秒**，相關 −0.88 |

例子（秒，負 = 快）：

| 場地 | pooled | 純路面 | 被吸收（馬質素） |
|---|---:|---:|---:|
| Flemington | −1.81 | −0.64 | **−1.17** |
| Randwick | −1.42 | −0.30 | −1.11 |
| Caulfield | −1.01 | +0.08 | −1.09 |
| Rosehill | −1.44 | −0.43 | −1.02 |
| Kilcoy | +0.92 | +0.73 | +0.19 |
| Narrandera | +0.82 | +0.58 | +0.24 |

**結論**：大城市場地「標準快」，大部分原因係嗰度跑嘅馬好，唔係條跑道快。一個按場地平均出嚟嘅標準會將
「好馬跑得快」當成「場地快」扣走 —— 一匹喺 Flemington 跑出好 L600 嘅馬，對住 Flemington 標準只係普通；
一匹鄉郊馬對住慢嘅鄉郊標準就睇落唔錯。即係標準**抹走咗能力差異**，正正同「反映能力」相反。

點解 EXP-31 喺排名度蝕：舊表 59% 賽事用「淨按路程」後備，**冇場地項**，所以嗰批反而保留咗質素資訊；
新標準將場地項伸延到全部場地，抹走嘅範圍更大。leaf AUC 仲升（+0.0072），係因為地況同同日修正帶嚟嘅改善
大過場地項嘅損失；但喺「同場馬嚟自唔同級數場地」嘅比較度，模型失咗分辨力。

# EXP-20261018-12 — HKJC 同程表現深入審查（2% centred）：同程往績被截斷

- **日期**：2026-10-18；平台：HKJC；**審查**，未改模型（修正方案等 Kelvin 決定）
- **結構**：V1 live —— 季內／同程行 `同程 (冠-亞-季-其餘)`：有上名 +4、跑過冇上名 −1.55（先加落班次分再遷移，
  實際綜合分影響約 4 × 0.75 × 14.28% ≈ **+0.43／−0.17 分**）。V2（同馬殘差）係 prospective shadow。

## 發現：同程往績只數到賽績頁列出嘅仗數

對賽果庫（2024-09 起完整 HK 賽果，`Date < 賽日`、同路程）9–10 月 1,427 匹：

| 檢查 | 結果 |
|---|---:|
| 同程出賽次數一致 | 855（60%） |
| **少數咗** | **566（40%）** |
| 同程上名次數一致 | 1,061（74%） |
| **賽果庫有上名、引擎以為冇** | **113（7.9%）** —— 應該 +4，實際 −1.55 或 0 |
| 引擎以為有上名、賽果庫冇 | 0 |

例：天星 1200m 引擎 (0-0-0-1)，賽果庫 11 仗 5 次上名；寶進 1200m (2-0-1-4) vs 12 仗 6 次上名；得道猴王 (0-0-2-4) vs 21 仗 6 次。
成因：Facts 生成器（`inject_hkjc_fact_anchors.compute_stats`）只數賽績頁列出嘅往績，舊仗唔喺頁面就唔計。
`best_distance`（「今仗 1200m = n場 (…)」）一樣截斷（1,245 匹入面 723 匹場數一致），唔可以當替代來源。

方向一致：截斷只會令「有上名」變「冇」，唔會反過嚟，所以系統性低估有同程經驗嘅馬。

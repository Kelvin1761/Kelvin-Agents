# EXP-20261122-03 AU 騎練「每仗平均獎金」代替／加落勝率 —— 預先登記（2026-11-22，跑之前寫）

- 起因：Kelvin 2026-11-22「should we use prize money also for trainer and jockey instead of 勝率？」→「測」。
  預期（寫低先跑）：取代會因為重複計匹馬實力而唔過；喺剩餘表現之上加唔到新資訊。
- 數據：`AU_Sportsbet_People_Snapshots.jsonl`「Prize Money / Last 12 Months」（按該仗贏到嘅獎金分組嘅出賽數）。
  每仗平均獎金 EPS = Σ 組出賽數 × 組中位 ÷ 出賽數（中位：2.5k／7.5k／15k／35k／75k／150k／350k／750k）；特徵 = log10(EPS + 1)，場內中心化，冇快照 = 場均。
  **as-of**：用賽日**之前**最近一份快照（08-09 起有）；名用 People Cache id → 名，賽果 CSV（日期、場號、正規化馬名）join 騎練名。
- 幅度：walk-forward logistic `入三甲 ~ a + b·(基準分 − 場均) + c_J·EPS_J + c_T·EPS_T`，β = c/b，限 [−30, 30]，頭 20 日 0。
- arm：
  - **P1 取代**：基準分 = 綜合分減走 jockey_score、trainer_score 兩個 leaf 嘅貢獻（兩個 leaf 設 60 重算矩陣）；候選 = 基準分 + β·EPS。對照 = 現行綜合分。
  - **P2 加落現行**：候選 = 綜合分 + β·EPS。對照 = 綜合分。
  - **P3 加落已上線剩餘表現**：對照 = 綜合分 + 練馬師剩餘表現（EXP-20261122-02 同一計法）；候選 = 對照 + β·EPS。
- 判決：`au_logloss_ruler.evaluate`，語料 `au-noise-20261113/BASE.json`；3 個 arm Holm。唔准改中位表、改 β 範圍、換語料或尺。

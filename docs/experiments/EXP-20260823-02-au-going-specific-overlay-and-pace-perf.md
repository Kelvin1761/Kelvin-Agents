## (A) 濕地 overlay 地況分離 —— KEEP

起因：Randwick R1 掛牌 **Soft 6**，Clear Proof 軟地 **7:2-2-0（4 上名 / 7 = 57%）**
本身係正數，但 2 場重地 0-0-0 把溝埋後嘅率拉到 4/9 → overlay **−0.571**；
Gunroom 軟地 4:1-2-0 ＋ 重地 1:1-0-0 → 4/5 → **+2.475**。clean 分落後 1.88 分嘅
Gunroom 單靠呢一項反超前。

**為咩係 ×0.5 而唔係完全分開** —— 按今日地況睇各種往績嘅場內 AUC：

| 今日地況 | 場次 | 軟地往績 | 重地往績 | 好地往績 | 軟+重溝埋 |
|---|---|---|---|---|---|
| Good | 190 | 0.5456 | 0.5220 | **0.5632** | 0.5508 |
| **Soft 5-6** | **309** | 0.5821 | 0.5264 | **0.5836** | 0.5876 |
| Soft 7+ | 62 | 0.5663 | 0.5440 | 0.5491 | **0.6000** |

Soft 7+ 同 Heavy 日，**溝埋版本反而係最強預測** —— 軟地往績對重地係有效嘅部分證據。
所以完全分開（只用對應地況）實測 t3prec **−0.67 ❌**。0.5 係量出嚟嘅折衷。

### 順帶：軟地其實同好地一樣（用戶提出）

Soft 5-6（佔 47% 場次）嘅「好地往績」AUC **0.5836** 同「軟地往績」**0.5821** 一模一樣
—— 即係軟地往績喺嗰度**冇地況專屬資訊**，只係一般能力嘅另一個量度。

**但剷走佢係蝕**：只 Soft7+/Heavy 生效 → Good位 −1.06、walk-forward 五個指標全負。
因為佢雖然冗餘，但仍然係**正向**訊號（AUC 0.58 > 0.50）。**冗餘 ≠ 有害。**

## (B) pace_figure 七個修法 —— 全部 REJECT

診斷全部**事實正確**：
- **race-level**：1,191 場共同往績，跨馬匹 100% 相同值（Sportsbet 冇逐駒段速）
- **混入試閘**：8,428 / 54,914 pf_runs（15.3%），影響 **46.4%** 馬匹
- **距離冇正規化**：1170m 平均 +1.997 vs 1110m −0.031；同距離下試閘系統性慢
  （1000m 試閘 +1.147 vs 正式 +0.436；1400m +3.954 vs +0.744）
- **細 SD 被放大**：Race 1 全場 l600 SD 只有 **0.272 秒**，Gunroom 差 0.28 秒 → z −1.05 → **+21 分**

| 修法 | 結果 |
|---|---|
| 上行壓縮（cap@70/75/80、half/quarter slope、sqrt） | 六個全部 CI 跨零 |
| 減 pace_perf 權重（0.10/0.08/0.06/0.04/0） | Good位 **−2.43 ❌**、首選上名 **−1.83 ❌** |
| × sectional 交互 | 係數 −0.0005 ≈ 0，ΔAUC −0.0006 |
| × form 交互 | 係數係**正**（互補，唔係「要證實」）|
| 剔走試閘 | t3prec **−0.87 ❌**、Pass −1.70 |
| 剔走 <1000m | Pass −1.54 |
| 剔走試閘 + <1000m | t3prec **−0.92 ❌** |

唯一嘅新資訊。** 佢 AUC 只有 0.539，但係 0.539 嘅**獨立**資訊。

### 三個分層檢定，全部同直覺相反

| 分層 | PF 場內 AUC |
|---|---|
| 場內 l600 SD ≤0.30（極同質）| **0.5524** ← 最高 |
| SD >0.45（散開）| 0.5362 ← 最低 |
| 0 個短程仗 | **0.5216** ← 最低 |
| 1-2 個短程（試閘）仗 | **0.5683** ← 最高 |

「同質馬群放大噪音」**唔成立** —— 同質正係 PF 最靈嘅時候。「試閘污染」亦唔成立 ——
有試閘仗嘅馬 PF 反而最準。呢個直接解釋咗為咩剔走試閘會蝕。

## 結論

**(A) KEEP** —— Gold +0.62 ✅、walk-forward Gold/Pass 從未負、機制正確。
**(B) 全部 REJECT** —— 七個修法、三個分層，全部話「粗糙版本 work，任何精修都輸」。

`pace_figure` 唔係公式問題，係**數據源**問題。要令佢由「賽事環境」變成「本駒能力」
就要逐駒段速，而 Sportsbet 冇。唯一出路係換源（Racing Australia 官方 sectionals）。

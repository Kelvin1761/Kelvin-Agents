## 量度

**描述**：配搭分（搬走前）≥ 72 嘅馬分兩組 —— 觸發（class_score < 58）同冇觸發（≥ 58）。
因為 class_score 本身會影響入位率，所以按 class_score 再分層比較，唔直接比兩組：

- 主比較：class_score 50–58 嘅觸發馬 vs 冇觸發而 class_score 58–66 嘅馬太唔對等，所以改用**條件化**：
  喺 class_score < 58 嘅馬入面，比較配搭分 ≥ 72（觸發）同 64–72（冇觸發、但接近）嘅超額入位率差，
  再同 class_score ≥ 58 入面同樣兩組嘅差比較（difference-in-differences）。
- 規則嘅假設 = 「班次證據弱時，高配搭分嘅額外價值較細」→ DiD 應該 < 0。
- **方向反** = DiD 95% CI（場次 bootstrap 2000、seed 7）全 > 0（即係弱班次時高配搭分反而更值錢，扣分係錯）。
- 超額入位 = 入位 − 派彩位數／馬匹數（8 匹以上 3 位，否則 2 位）。

**term ablation**：剷走規則（重算 fit 時唔行 −3），v3 `fixed_rule` 全紀錄 + 預先聲明分層，另報跑包尾。

## 判決（預先定）

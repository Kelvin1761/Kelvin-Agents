## 三、逐 leaf 表大部分係循環論證（唔好照讀）

A 群入面比較「我哋漏咗嗰匹」vs「我哋錯捧嗰匹」嘅場內 z 差，**有權重嘅 leaf 必然係負**
—— 因為我哋就係用嗰批 leaf 排名，所以我哋捧起嗰匹一定分數高。負值**唔代表 leaf 指錯**。

唔受循環影響嘅只有零權重嗰三個：

| leaf | z 差 | 權重 |
|---|---:|---|
| `pace_map_score` | **+0.213（CI 不跨零）** | 0 |
| `formline_score` | +0.103 | 0 |
| `weight_score` | +0.065 | 0 |

呢個曾經睇落係大發現（「唯一指對方向嘅 leaf 全部係我哋唔計分嗰批」），但正式 A/B
之後 **REJECT**（見 [[EXP-20260831-14]]）。再一次：cohort 超額 ≠ 因果貢獻。

## 四、決定性測試：市場剩落嗰份資訊同我哋成套特徵正交

逐匹馬計 `分歧 = z(−log SP) − z(ability)`，取分歧最大嘅兩端各 10%（1,781 匹）：

| | 實際入位率 |
|---|---:|
| 市場遠比我哋看好 | **41.4%** |
| 市場遠比我哋看淡 | **16.5%** |

`ρ(市場分歧, 結果) = +0.1490` —— 市場多出嗰份資訊**確實有值**。

**但 18 個 leaf 冇一個指住嗰邊：**

| leaf | ρ(leaf, 市場分歧) | ρ(leaf, 結果) |
|---|---:|---:|
| `health_score` | +0.0375 | 0.0266 |
| `pace_map_score` | +0.0361 | 0.0290 |
| `trial_score` | +0.0353 | 0.0929 |
| … | | |
| `pace_figure_score` | **−0.2038** | 0.1262 |
| `performance_quality_score` | **−0.2362** | 0.1939 |
| `form_score` | **−0.2898** | 0.1662 |

最強嘅正相關係 `health_score` +0.0375（可忽略，而佢自己都幾乎唔預測結果）。
所有**真正**預測得到結果嘅 leaf 同市場分歧**全部負相關** —— 即係我哋已經食晒嗰批
資訊，市場剩落嘅優勢**同我哋成套特徵正交**。

## 五、結論

**缺口係資訊，唔係配權。** 重新配權、加條件式權重、換 leaf 組合都動唔到呢 7.3pp ——
因為我哋手上冇任何欄位帶住嗰份訊號。呢個直接解釋咗 [[au-feature-set-is-saturated]]
（GBM 喺同一批 leaf 上輸現行線性組合）同 [[au-market-benchmark]]（冇混合贏得到市場）。

⚠️ **一部分係結構性攞唔到嘅**：SP 係最終價，含埋開閘前所有落注（馬房消息、當日場地
判斷、後期熱錢）。呢啲喺我哋落注嗰刻根本唔存在，所以 ρ=0.149 有一部分永遠追唔到。

### 可以做嘅方向（未測）

要縮呢個缺口只有一條路：**加新資訊來源**，唔係重組現有嘅。按正交性最高排：
1. **賽事評述／申訴**（`Race_Results_*.json` 個 `comments` 欄已經有，但只覆蓋 36 場次）
2. **馬房／騎師當日整體動向**（同一日同一馬房其他馬嘅市場反應）
3. **配備變更**（[[EXP-20260826-07]] 量到 OFF FIRST TIME −3.86pp 顯著，但同 form 重複）

⚠️ 第 2 條要非常小心：佢本質上係市場價嘅 proxy，而 methodology 冇寫住賠率係模型一部分
（見 AGENTS.md「賠率／市場價唔准做隱藏 proxy」）。要用就要先改 methodology。

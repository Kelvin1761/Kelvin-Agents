## 特徵

只用賽前資料：今場退出後檔位（Racecard），同場出賽馬。設 n = 出賽馬數，b = 檔位，場內按 b 排 0（最內）→ n−1（最外）。

- **z 版**：`d = −z(排名)`（場內標準化；8 匹同 20 匹最內同最外都係同一個 z 範圍）。
- **raw 版**：`d = −(排名 − 場內平均排名)`（單位 = 檔位數；20 匹嘅最外檔離中間 9.5 格，8 匹只係 3.5 格 ——
  **即係「20 匹時檔位影響更大」由公式自然帶出**，用同一個係數）。

## 排名分

`候選綜合分 = 現行綜合分 + β × d`（n 未到門檻 → 0）。β 用 **walk-forward**：每個賽日 D，用 2026-08-05 → D−1 嘅全部合資格場次，
擬合條件 logit（上名 = 頭三）`u = a × 綜合分 + c × d`，β = c ÷ a（換成綜合分單位）。頭 21 個賽日（warmup）β = 0。

## 判決

- v3 `walk_forward_oos` 全紀錄（08-05 → 語料最後一日），bootstrap 以賽日 2000 次、seed 7；
  ranking metric `top3_capture_at5`、`ndcg_at5`、`top5_pairwise_auc`。
- 4 個 arm 用 `holm_adjust`（每個 arm WIN 所依嘅最細 p）；Holm 後 p < 0.05 先算 WIN。
- 分層（預先聲明）：馬匹數 ≤8／9–12／13+、首選 SP、路程三段、首選跑法；另加 **14+ 匹**。
- 多過一個 arm WIN → 揀 Holm p 最細；同 p 揀簡單啲（Z8 ＞ Z10 ＞ R8 ＞ ZD8）。
- 上線用嘅 β = 用同一程序、喺上線日之前全部乾淨數據擬合嘅值，寫死做常數（之後要另外登記先可以改）。

## 解讀
- 跑法偏差：喺某個跑道格前領／後追系統性著數（例如跑馬地 C+3 前領），而現有步速形勢維度未完全捉到。效應細（機率準度改善，排名幾乎唔郁）。
- 檔位偏差：dev 真，但 holdout 減半、CI 跨零 —— 現有檔位分已經捉到大部分。
- 上仗逆偏差（「上仗蝕位今仗會好」）：冇訊號，方向仲相反（上仗被偏差蝕嘅馬今仗都唔好）。
- 上線（S）：Kelvin 決定。

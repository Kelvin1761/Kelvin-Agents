# EXP-20261124-41 AU log-loss 尺 null 不對稱（v2.1）—— 判決完全唔變，唔換尺

- 日期：2026-11-24　平台：AU　類型：把尺審查（獨立改動，冇同任何候選一齊改）
- 來源：Codex Sol 覆核 `au_logloss_ruler.py`（2026-11-24）。

## 問題

`evaluate()` 實際 Δ 計晒所有計分場次（候選冇郁到嘅場次都有「baseline／candidate 各自校準」嘅差），
但場內洗牌 null 遇到冇郁嘅場次就 `continue`，即係 null 冇呢份 —— 兩邊唔係同一把尺。理論上只郁一小撮馬嘅候選最受影響。
另外 `evaluate()` 只核對場次一致，冇核對逐匹次序。

## v2.1（研究選項 `version="v2.1"`，預設仍然係 v2）

- null 每次加返冇郁場次嘅實際貢獻（洗牌一堆 0 都係 0，所以佢喺 null 同實際一模一樣）；
- 逐匹次序（`n` 或 `name`）唔一致就 raise。
- 校準、護欄、bootstrap 全部同 v2。

## 結論

不對稱係真，但實際影響細到唔改判決（冇郁場次嘅校準差相對細）。**唔換預設尺**（換尺要有判決差先值得；
「簡單穩健 > 複雜邊際」）。v2.1 留做研究選項，遲啲有只郁極少數馬嘅候選可以兩把都報。合約唔改。

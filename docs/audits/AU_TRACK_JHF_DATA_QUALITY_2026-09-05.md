## 結論

1. **`track_score` 過關。** 覆蓋齊、單調、cohort 方向啱、傳導中游。
   唯一要修係 `going_bucket` 對 Synthetic／空白 going 靜靜當好地（1.5%）。
2. **`jockey_horse_fit_score` 來源齊，但形狀有兩個問題**：中間 50% 打橫（「亂」），
   同埋餵佢嘅 `top_jockey` 閘 79.4% 情況靠 9 個 token 嘅 substring 比對，
   實測擦錯人（`Clarke`⊃`Clark`、`Bottomley`⊃`Bott`）。
3. **可以即刻做而且合乎評估合約第 7 節（正確性修正）嘅得一件**：
   將 `_is_top_jockey`/`_is_top_trainer` 由 59/56 行嘅 CSV + token 名單，
   改為查已經存在嘅 2,255 人騎練庫。判斷標準過關 ——
   **就算績效數字係相反方向，`Sheridan Clarke` 都唔應該因為個姓包住 `Clark`
   而被當成頂級騎師。** 仍然要零顯著退步 + leakage PASS + 明文寫「唔係已證實嘅改善」。
4. **唔好做**：憑呢份審計去加 `track_score` / `jockey_horse_fit` 嘅權重。
   排名尺上佢哋傳導中游，而重配份額已經連續失敗五次
   （`au-reallocating-dimension-shares-fails`）。

## 4. 死 code：條式寫咗但從來冇入分（排名中性，可以 §7 清走）

## 5. 逐維度：條式量緊乜、啱唔啱

### 5.1 狀態與穩定性（8.85%）—— 量得啱，條式粗

- form_score：近 6 仗名次 → 1=100、2=85、3=75、4–5=60、6+=40，按 1/(i+1) 加權。
  **唔理輸距、唔理馬匹數**：第 6 名輸半個馬位同第 14 名輸 20 個馬位一樣係 40。
  最常見值就係 40（18%）。
- consistency（實際用嘅 shadow 版）有計輸距（≤3 個馬位當跑近），所以兩個 leaf 雖然
  ρ 0.82，consistency 補返 form_score 缺嘅輸距。
- 判斷：**合理**。全模型最準嘅維度，冇證據顯示條式錯。form_score 嘅「6+ 一律 40」
  係一個可以試嘅細化（例：第 6–7 名輸 ≤3 個馬位唔當 40），但 consistency 已經捉咗
  大部分，預期增量細。

### 5.2 騎練訊號（23.62%）—— 合理；練馬師 leaf 差唔多冇離散度

- jockey / trainer = 兩季 EB 收縮實績分，細樣本先同層級先驗混合；再加六個情境項
  （人馬往績、組合、騎師／練馬師同程、換騎）同除去配備 −3。
- trainer_score 場內 SD 只有 **2.56**（jockey 7.06），但佔 45% 份額 —— 即係份額寫 45%，
  實際影響力大約只係 jockey 嘅 1/3。EXP-03 診斷亦指向 jockey 份額 ~0.70，但量唔出差別。
- 判斷：**合理**。六個情境項成套有用（EXP-20261018-03）、換騎方向冇問題。冇要郁。

## 6. 結論

1. **冇搵到會令排名錯嘅公式 bug。** 第一至三步之後，九個維度冇一個顯著反向（晨操 AUC 0.4883 略低於 0.5，但影響力只佔 1%），
   冇搵到「越好分數越低」嘅條式。
2. **死 code 有三處（第 4 節 1–3）**：風險分成條被覆蓋、晨操扣分下限到唔到、
   穩定性後備路徑。全部排名中性，可以做一個 golden 守住嘅清理。
3. **標籤錯配有兩處**：馬匹健康有四成係負磅；級數優勢量嘅係經驗唔係班次。
   改 description 係純顯示；搬 leaf 係模型改動，第 2 步已經量過量唔出。
4. **值得第 5 步先量嘅只有兩樣（純數據，未郁模型）**：
   - 沙田直路 1000 米檔位先驗（樣本唔支持外檔 +27 分，要全歷史量）；
   - L400 門檻按場地／路程分（已知平均差 ~1 秒）。
5. **唔建議**：再郁外層權重、內部份額、race_shape 消融、賽績線分數表 —— 全部已經量過。

## 7. 限制

- 365 場、單一時期（2026-04 → 10）；AUC 係描述，唔係評估閘。
- 「影響力」冇計相關，只係量級參考。
- 直路 1000 米只有約 21 場，第 5.4 節嗰個表**唔係證據**，只係「要量」嘅理由。

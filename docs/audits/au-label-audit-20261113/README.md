## 方法

1. **標籤追 code**：由一份實際報告（2026-11-12 Eagle Farm R5）逐行出發，追返去 `au_racing_engine/`、
   `.agents/scripts/inject_fact_anchors.py`。✔ = 已逐行睇過 code 確認。
2. **訊號量度**：2026-10-01 → 2026-11-11 **實際發佈**嘅 `Race_*_Auto_Scoring.csv` 對
   `AU_Historical_Raw_Race_Results.csv`，1,804 場、17,305 匹（`build_corpus.py`、`measure_leaves.py`）。
   - 場內 AUC：同場隨機一匹前三 vs 一匹落榜，個分高嗰匹係前三嘅機率（0.50 = 冇資訊）。預設剔走 = 60（overlay = 0）嘅馬；
     CI = 按場 bootstrap 1,000 次。
   - 「中性比例」= 分數啱啱等於 60（overlay 0）；「場內常數」= 成場一個值。
   - ρ(總分) = 場內 Spearman 對 `final_rank_score`（高 = 同總分重複，低 = 正交或者冇用）。
   - ⚠️ 呢個窗用嘅係**當時嘅 live 引擎**，期間有改動（例如 `form_quality_score` 10-16 先有欄位、`draw_feature` 11-02 先上線）。
     呢度量嘅係「用戶睇到嘅嘢有冇資訊」，**唔係**判決級 A/B，唔可以用嚟擇權重。

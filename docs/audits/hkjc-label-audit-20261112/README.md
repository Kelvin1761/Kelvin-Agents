## 顯示性／死值

- 晨操維度：`TRACKWORK_SCORING="off"`，全部馬 60（顯示約 56.1 ❌ 偏弱），權重仍然 0.98%（排名中性）
- 頭段速度、引擎信心：喺段速逐項度顯示「理由」，但權重係 0
- 已建立賽駒 +4：香港出過 1 仗就算
- 兌現度 v/n：n 係對手行數（每場最多 3 行），唔係場數
- 騎練標籤「騎師實績強」：維度係騎師 55％＋練馬師 45％
- 騎師同程／練馬師同程：只按路程，唔分場地
- 場地偏差：馬會長期檔位統計，唔係當日偏差；冇 scorer 讀 `track_bias`
- 0.389 分/kg：單位寫反（應該係 kg／評分分），香港用磅
- 段速「持續快於標準／略快於標準」分支：上游永遠唔出，死 code
